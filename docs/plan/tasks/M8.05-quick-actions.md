## Goal
Add `UIApplicationShortcutItem`s for Today, Yesterday (shown only while yesterday is open), "Skip the rest of today" and This week. One `QuickActionRouter` dispatches them. The skip action writes skip only into blanks, through `Recorder`, and lands on the board. DEBUG `-uiTestShortcut <type>` dispatches an action at launch.

## Why it matters
These replace the PWA manifest shortcuts (HANDOFF §8; decisions Q4, Q10b amendment 2).
