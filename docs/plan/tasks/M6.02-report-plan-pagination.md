## Goal
`ReportPlan.make(draft, record, now)` returns an ordered list of sheet models:
1. summary;
2. provenance;
3. one sheet per tracker (a chart, or a shortfall);
4. pairs;
5. the day table;
6. notes.

Rows are measured in lines, with a fixed number of rows per Letter sheet. A section never starts in the middle of a sheet. A continuation sheet carries "{section}, continued". Every sheet carries the footer. Labels use the absolute range.

## Why it matters
§7 asks for the full sheet set. Keeping pagination pure makes every rule testable without rendering.
