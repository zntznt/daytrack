## Goal
Add pure `Copy` functions for every user-facing string the MVP needs that depends on data:
- the amend chip: "until {weekday} {HH}:00";
- the Settings label "Yesterday stays open until", which reads "00:00 · no grace day" at lockHour 0;
- the dot strip: "{n} written, {k} skipped, {b} still blank";
- the value accessibility label: "{tracker}, {word or number | skipped | not written yet}. Activate for choices";
- the pad keys "Skip {tracker}" and "Leave {tracker} blank";
- "Skip the rest of {dayLabel}", where dayLabel is "today" or "yesterday";
- the note footer, which names the same close time as the chip;
- the fact line "Last full copy: 12 Jul (11 days ago)", or "No copy saved yet";
- `dayLabel(for:now:)`.

Use 24-hour HH:00 and locale weekday abbreviations through a `Locale` parameter. Tests pin `en_US_POSIX`.

## Why it matters
design-review High 1 found 23:00, 23:59 and "midnight" all in use for the same rule. A single source makes drift impossible. Later tasks add their strings here, in this folder.
