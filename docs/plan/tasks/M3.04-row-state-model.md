## Goal
`RowState` is a pure value type in `App/Today/`. Given a tracker, a value, yesterday's value, the track width and the entry mode, it provides:
- `stop(atX:)`: press-to-position, quantised to the nearest stop;
- `stopsCrossed(from:to:)`, which drives one selection tick per stop crossed and none on release;
- `commitValue`, applied on drag end only;
- `increment()` and `decrement()`, which step one stop and clamp;
- `accessibilityValue`: the word for ordinal and binary trackers, the number for numeric ones, "skipped" or "not written yet";
- `valueButtonLabel` and `padOptions`. "Leave {tracker} blank" is offered only when the row is set or skipped. All strings come from `Copy`.

## Why it matters
XCUITest drags and haptics are flaky. Putting the gesture maths in a model makes "the only component that really matters" (HANDOFF §3) deterministic to test.
