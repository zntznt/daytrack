## Goal
- `CopyFileCodec`, JSON schema v1. It holds `schemaVersion: 1`, Settings (lockHour, closedThrough, reminderAt), trackers, revisions, archive ranges, and entries with every provenance field and the note. It never holds DeviceState: lastFullCopyAt, reportDraft or remindersScheduledThrough.
- `fileName(on:)`, which returns `daytrack-YYYY-MM-DD.json` in local time.
- `decode`, which returns `.copy(Record)` or `.refused(.notJSON | .noDays | .newerVersion(Int))`.
- `CSVExport`: one row per day and one column per tracker, with `skip` written distinctly from an empty (blank) cell. A header comment line states that CSV is lossy.

The record store in M2.01 uses this same codec, so the file on disk and the saved copy share one schema.

## Why it matters
"Save a full copy" is the only copy that exists (Q2, Q8). It must be lossless, and files saved during the MVP must be restorable later by M7.
