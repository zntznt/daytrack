## Goal
- Render every sheet in the plan with `ImageRenderer` into a CoreGraphics PDF context at Letter size (612×792).
- Write `daytrack-report-YYYY-MM-DD.pdf` to a local file first.
- Then offer the file through `ShareLink`. Printing goes through the share sheet.
- The builder's Generate button produces the file.

## Why it matters
The report reaches the clinician on paper, with no library.
