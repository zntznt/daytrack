## Goal
On first run, the user picks starters from `StarterCatalog`. At least 1 and at most 8 can be picked.
- A disabled Start button states its reason underneath.
- A 9th pick is refused with "Eight fit on one board. Archive one to make room."
- Start calls `TrackerManager.startBoard(picked:)` and lands on the Today tab (rows arrive in M3.07).
- The copy promise from decisions Q2 "Onboarding": "Keep a copy whenever · One tap saves a file you keep. Daytrack never sees where it goes." No mention of iCloud, Google Drive or any cloud (design-review High 5).

## Why it matters
Without trackers there is no board. Q11b requires that only the picked starters are created, so there is no phantom archive.
