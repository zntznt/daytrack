## Goal
Build one `DesignSystem` module:
- `AmbientBackground`: a warm gradient in the 60–100 hue band, with no grey.
- `.glassSurface(radius:)`: `glassEffect` in a rounded rectangle, using the radius tokens.
- `GlassGroup`, which wraps `GlassEffectContainer`.
- `GlassStyle.resolve(reduceTransparency:increaseContrast:)`, which returns `.glass`, `.solidWarm` or `.solidWarmBordered`. It reads the environment, and `-uiTestLegibility` overrides it.
- Tokens: amber accent, and a text hierarchy expressed by lightness.
- `Typography`: system SF with Dynamic Type (`relativeTo:`), and monospaced digits for numerals **[O6]**.
- `PrimaryButton` and `Chip`. Every hit target is at least 44pt.
- A DEBUG catalog screen, reached with `-uiTestScreen catalog`, that shows each atom over the background.

## Why it matters
Every screen uses these tokens, so legibility problems must be caught now. The owner decided on full Liquid Glass, and it must still pass with Reduce Transparency and Increase Contrast on.
