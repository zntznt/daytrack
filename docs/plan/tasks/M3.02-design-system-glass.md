## Goal
Build one small `DesignSystem` module, using **native** Liquid Glass only (decisions "Owner decisions" → Visual, revised 2026-11-27):
- `Tokens`: amber accent, a warm-dark background colour, and a text hierarchy expressed by lightness in the warm hue band (no grey).
- `AmbientBackground`: the warm content backdrop (a subtle warm gradient). It is content, not glass.
- `Typography`: system SF with Dynamic Type (`relativeTo:`), and monospaced digits for numerals **[O6]**.
- Glass comes only from system components: `.buttonStyle(.glass)` and `.buttonStyle(.glassProminent)` for buttons and chips, and the native tab bar, navigation bars and sheets. **No custom `glassEffect`, `GlassEffectContainer` or glass resolver.**
- A DEBUG catalog screen, reached with `-uiTestScreen catalog`, that shows the type scale, the colour tokens, a `.glass` and a `.glassProminent` button, and a row of `.glass` chips over the background. Every hit target is at least 44pt.

## Why it matters
Every screen uses these tokens. Using Apple's own glass components means the system handles Reduce Transparency, Increase Contrast and glass legibility, instead of the app re-implementing them.
