## Goal
`ChoicePadView` is presentational and is shown in a native sheet, which gives it system Liquid Glass; it adds no custom `glassEffect`. It shows:
- one key per stop;
- "Skip {tracker}";
- "Leave {tracker} blank", only when the row is set or skipped.

Each key commits and closes on the same frame, with no transition. Clearing is offered only while the day is open.

## Why it matters
Owner decision Q4: no single tap erases a value. Skip takes two taps through the pad.
