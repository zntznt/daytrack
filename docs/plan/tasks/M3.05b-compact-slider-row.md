# M3.05b Compact slider row so eight fit on one screen

| Field | Value |
|---|---|
| Milestone | M3 MVP |
| Size | S |
| Depends on | M3.05, M3.06 |
| Branch | `feat/m3.05b-compact-row` |

## Goal
Make `SliderRowView` at most 72pt tall without shrinking any hit target below 44pt, so eight rows fit between the day header and the tab bar on iPhone 18 Pro and iPhone 17e. Layout:
- Line 1: the tracker symbol and name as a non-interactive label, in a compact role (about 20pt line height).
- Line 2, 44pt tall: the track (flexible width, 44pt hit height), then the value button at its right end (at least 58×44pt, still a separate element that never overlaps the track).
- Spacing between the lines: 4pt at most.

## Why it matters
HANDOFF opens with "Eight things, one screen, ten seconds", and decisions Q11a caps the board at eight for that reason. At 92pt per row, M3.07 measured that row 7 falls under the tab bar (736pt needed, about 729pt available on iPhone 18 Pro). The owner keeps the one-screen promise rather than scrolling or lowering the cap.
