## Goal
Owner feedback after the first install on the iPhone 17 Pro:
- **Rows fill the board.** With up to 8 trackers, the rows share the height the board has free, so the screen does not end in empty space. Row height = free height ÷ row count, clamped to 72–112pt. At the minimum (8 rows on iPhone 17e) behaviour is the same as today: no scrolling. With fewer rows they grow up to the cap and the board stays top-aligned. The track and value button stay one 44pt line; the extra height goes to vertical padding and a slightly larger name label, not to a taller track. Measure with `onGeometryChange` or `containerRelativeFrame`, not a GeometryReader that collapses the scroll view.
- **Choice pad keys fit their words.** Ordinal stops ("Absent" … "Severe") are never truncated or squeezed. Short stops such as numbers keep the adaptive grid. When any stop label is longer than 3 characters, lay the stops out one per row as full-width glass keys, the same as the Skip/Blank keys. Keys are at least 44pt tall and use Dynamic Type.
- **The dot strip breathes.** Add a spacing token (`Tokens.Space`, with values like 8/12/16/24) and give the strip at least 16pt above the first row. Use the token in TodayView instead of literals.

Native glass rule unchanged: system button styles only, no custom `glassEffect`.
