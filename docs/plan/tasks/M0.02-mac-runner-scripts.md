## Goal
Make one command on Linux build and test a pushed branch on Thunderbolt and return its exit code. Add the scope, size, commit and named-test checks that make up the Definition of Done.

## Why it matters
Every later acceptance criterion runs through these scripts. They are also the mechanical guard against agents drifting off task.

## Read
- `docs/plan/README.md` §2 ("Rules that lint enforces"), §3 (all), §4 (Definition of Done)
- `rex run --help` and `rex capture --help`

## May touch
```scope
scripts/mac
scripts/verify.sh
scripts/scope.sh
scripts/done.sh
scripts/lint-allow.txt
.gitignore
```

## Do
- `scripts/mac`: Linux, bash. Implement it exactly as README §3 describes. First confirm the JSON field that holds the block id by running `rex -S Thunderbolt run -s daytrack --json --shell=none --focus=false --wait -- true`, and note the field in a script comment.
- `scripts/verify.sh`: Mac, bash, `set -euo pipefail`. Implement the targets `core`, `app`, `lint`, `lint-selftest`, `all`, `shots` and `device` with the exit codes in README §3. `app`, `shots` and `device` may print "no project yet" and exit 0 when `project.yml` is absent. M0.03 removes that.
- `scripts/scope.sh <ID>`: read the ```` ```scope ```` block from `docs/plan/tasks/<ID>-*.md`. With `shopt -s globstar extglob`, match every path in `git diff --name-only origin/main...HEAD` against those globs, and print each offending path. Exit 1 if any path is outside them.
- `scripts/done.sh <ID>`: the six steps in README §4, in that order. Print `DONE OK <ID>` on success.
- `scripts/lint-allow.txt`: empty for now, with one header comment line.

## Out of scope
- GitHub Actions or any CI service.
- Installing anything on the Mac. The owner does G1.
- Any Swift code or `project.yml`.

## Acceptance (done.sh is created here; run these literally)
```
scripts/mac lint                                  # exits 0, prints the remote output
scripts/mac lint-selftest                         # exits 0
scripts/mac nonsense; test $? -eq 64
scripts/scope.sh M0.02                            # exits 0 on this branch
```

- `lint-selftest` fails if any one rule is disabled. Show this by temporarily commenting a rule out locally. Do not commit that change.
- `scripts/done.sh M0.02` exits 0. Its tests block is empty.
