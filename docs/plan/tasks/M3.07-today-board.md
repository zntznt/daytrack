## Goal
`TodayContainer` owns a `TodayModel`, an @Observable that calls `Recorder`. `TodayView` shows:
- the day name;
- one plain content row per active tracker (no glass), in roster order;
- the dot strip, from `Copy`;
- the "Skip the rest of today" day action;
- boardEmpty, when every tracker is archived: the dot strip is suppressed entirely, a dashed panel says the record is untouched, one "Bring one back" action links to Settings › Trackers (a placeholder until M3.15), and the closing line says there is no nudge tonight (HANDOFF §9).
- Day one: copy that never implies lateness. There is **no** "Tap the number to skip" hint (decisions Q4 drops it); the value button's label is the skip affordance on every row (design-review Medium 12).

Commit happens on drag end through `Recorder.write`. The board never re-renders under a moving finger, because the model holds its updates while `isDragging` is true. Eight rows fit without scrolling.

## Why it matters
This is the whole daily ritual, and it closes the core write loop on the simulator.
