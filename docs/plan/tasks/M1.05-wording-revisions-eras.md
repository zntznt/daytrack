## Goal
- `ScaleRevision(trackerId, effectiveFrom: DayKey, previousLabels)`. The `previousLabels` count must equal the tracker's stop count.
- `Eras`: `eras(for:)`, `labels(tracker, on:)`, `latestEra(in range)` and `boundaries(in range)`.
- `Record.swift`: the plain aggregate `Record { settings, trackers, revisions, entries }` and `Settings { lockHour = 23, closedThrough: DayKey?, reminderAt: (hour, minute)? = 21:30 }`. No Codable yet (M1.09 adds it). It is created here because the summaries, floors and reminder plan all take a Record.
- `WordingEditRule`: a wording edit is free until a closed day holds a value (set or skip) for that tracker. After that, an edit creates a revision effective today. The same rule covers numeric anchors. A change to the stop count throws `.stopCountIsFixed`.

## Why it matters
No statistic may cross a wording boundary (rule 7). This area produces "the worst bug": a silent re-score.
