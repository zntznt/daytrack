## Goal
- Add the **History** tab. The tab order is now Today, History, Settings; Report arrives in M6.03.
- Range chips come from `HistoryRanges`.
- A Swift Charts range chart. Each contiguous run of set days is its own series, so a gap stays a gap. Revision boundaries are drawn with `RuleMark`.
- A tracker list with era-windowed values from `TrackerSummary`: k of n for binary trackers, median with n for ordinal ones.
- The historyEmpty state, with the calendar affordance always shown.
- The chart has an accessibility summary that mentions gaps.

## Why it matters
Rule 4 (no imputation) and §6 on screen. This is the main place where design-review High 9 must not recur.
