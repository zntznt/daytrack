## Goal
Owner feedback: Settings buttons look dark grey, unlike the glass buttons on Today, and the Daily reminder screen has a different background altogether.
- Add one view modifier `.daytrackList()` in `App/DesignSystem/`. It applies `.scrollContentBackground(.hidden)`, `AmbientBackground`, and a warm row background from Tokens (`Tokens.surfaceRaised`, add it if missing) in place of the system grey. Apply it to every `List`/`Form` screen: Settings, Trackers, Archived, Daily reminder, and the lock-hour picker list (push it as a `navigationDestination` list instead of `.pickerStyle(.navigationLink)` so it can be styled, keeping the confirm flow).
- Actions in Settings that are buttons, not navigation rows, use the same native glass button style as Today: Save a full copy uses `.glass`, Erase everything uses `.glass` with a destructive tint, and Remind me uses `.glassProminent`. Navigation rows stay rows.
- Add lint rule 5 to `scripts/verify.sh`: any Swift file under `App/` containing `List {` or `Form {` must also contain `.daytrackList()`, so a new screen cannot miss the backdrop again. Add its self-test fixture to lint-selftest.
