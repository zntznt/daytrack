## Goal
Add an "Entry" switch in Settings with three modes: drag, stepper and large. The setting is stored in Settings as `entryMode` and exported.
- **Stepper:** a 6pt track with no handle. The value is a 58×44 button that opens the pad, with − and + buttons beside it.
- **Large:** bigger tracks, handles and targets, with a visible scroll cue when rows overflow.
- Text always follows Dynamic Type.
- Yesterday's value shows in every mode.
- Switching modes never changes stored data.

## Why it matters
These modes serve people with a tremor or low vision (HANDOFF §3, §10). They close design-review Medium 13.
