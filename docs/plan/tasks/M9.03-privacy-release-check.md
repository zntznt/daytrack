## Goal
- `App/PrivacyInfo.xcprivacy`, and one for the widget. Both declare no tracking, no collected data, and only the required-reason APIs actually used, such as file timestamps and UserDefaults if they are used.
- No ATS exceptions and no network entitlements.
- A hosted test checks the real store file's backup exclusion and its file protection class on the simulator.
- A Release check: build Release, then confirm with `strings` that the binary does not contain `uiTestNow`, `uiTestStore` or `uiTestSeed`, so the DEBUG overrides are absent.
- Add a "Release checklist" section to `docs/plan/README.md`.

## Why it matters
Rule 1 must stay literally true in the shipped binary.
