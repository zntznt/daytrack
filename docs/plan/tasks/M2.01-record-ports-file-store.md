## Goal
- `DeviceState`: lastFullCopyAt, reportDraft (as `Data?` until M6.01) and remindersScheduledThrough. It is never exported.
- Ports: `RecordStore` (`load() throws -> LoadResult`, `save(Record)`), `DeviceStateStore`, `Clock`, `ReminderScheduling` (`replan(record:now:)` and `removeAll()`) and `WidgetPublishing` (`publish(record:now:)`).
- `InMemoryRecordStore`, `InMemoryDeviceStateStore` and `FixedClock`, for tests and UI tests.
- `FileRecordStore` in DaytrackStorage. It writes to an injected directory URL:
  - `record.json` through `CopyFileCodec`, written with `.atomic`;
  - file protection `.completeUntilFirstUserAuthentication`, so a background notification action can write after first unlock;
  - `isExcludedFromBackup` set on the directory after every save;
  - a missing file loads as `.empty`;
  - a file that cannot be decoded is renamed to `record-unreadable-<ISO timestamp>.json` and reported as `.unreadable(keptAt: URL)`. It is never overwritten;
  - `device.json` is a separate file.
- Note in code: `shortcut: whole-file rewrite per save, move to SQLite past ~5 MB`.

## Why it matters
Durability, the backup exclusion that rule 1 relies on (Q8), and no silent data loss. Every adapter plugs into these ports.
