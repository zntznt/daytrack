# M9.05 App icon

| Field | Value |
|---|---|
| Milestone | M9 Hardening |
| Size | S (the PNG is binary and does not count) |
| Depends on | M0.03. Off the MVP path: it may be pulled forward at any point after M0.03 |
| Branch | `build/m9.05-app-icon` |

## Goal
Give the app its icon mark from HANDOFF §8: an amber `#f6ac00` tile with three dark `#2c1200` bars at 100%, 55% and 78% width.

- `scripts/make-icon.py` draws a 1024×1024 opaque PNG using only the Python standard library (`zlib`, `struct`). Square corners: iOS applies the mask.
- Commit the output to `App/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` with a single-size `Contents.json`, and set `ASSETCATALOG_COMPILER_APPICON_NAME: AppIcon` in `project.yml`.

## Why it matters
The owner's phone shows a blank icon until this lands. The PWA icon set was deliberately not imported (M0.01), and nothing may be downloaded.

## Out of scope
- Widget icons, alternate icons, dark and tinted variants, and the PWA icon set.
- Any image tool, package or download.

## Acceptance
Run `scripts/done.sh M9.05`. Also run on Linux: `python3 -I scripts/make-icon.py /tmp/icon.png && cmp /tmp/icon.png App/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` (the committed PNG is reproducible).

```tests
appIconNameIsSetInBundle
```
`appIconNameIsSetInBundle` reads `CFBundleIcons.CFBundlePrimaryIcon` from the app's Info dictionary and checks that it is present.
