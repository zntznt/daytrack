## Goal
The Settings tab has, in this order:
1. **Trackers** (first row; a placeholder until M3.15)
2. **Day:** "Yesterday stays open until" with an hour picker from 0 to 23. The label is derived. Lowering the lock hour below the current time asks a one-line confirm through `SettingsService`.
3. **Data:** an empty section that M3.11 fills
4. a version line

## Why it matters
The owner needs to set the lock hour on the phone. Later tasks hang their rows here.
