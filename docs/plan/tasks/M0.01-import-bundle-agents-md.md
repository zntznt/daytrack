# M0.01 Import the design bundle and write AGENTS.md

| Field | Value |
|---|---|
| Milestone | M0 Foundations |
| Size | S (text only; the PNGs and HTML are moved, not written) |
| Depends on | Owner gate G0: `chore/design-docs` (with `docs/plan/`) is merged to main |
| Branch | `docs/m0.01-bundle-agents` |

## Goal
Move the durable design bundle to `docs/handoff/`, and give agents one entry rulebook at the repo root.

## Why it matters
Every later task reads `docs/handoff/...`. Without a root `AGENTS.md` and `CLAUDE.md`, an agent will not find the brief and will drift into PWA or Android work.

## Read
- `docs/plan/README.md` §1, §3, §4
- `docs/plan/AGENT_BRIEF.md` (all)

## May touch
```scope
docs/handoff/**
docs/plan/handoff/**
AGENTS.md
CLAUDE.md
.gitignore
```

## Do
1. `git mv docs/plan/handoff docs/handoff`. If `docs/plan/handoff` is missing, stop and ask the owner. Do not recreate it.
2. Write `AGENTS.md`, under 30 lines. It contains:
   - "Read `docs/plan/AGENT_BRIEF.md`, then your task file in `docs/plan/tasks/`";
   - the doc precedence list, copied from AGENT_BRIEF §1;
   - "Definition of Done: `scripts/done.sh <ID>` exits 0".
3. Write `CLAUDE.md` with the single line `Read AGENTS.md before any task.`
4. Write `.gitignore` with these entries: `build/`, `.build/`, `.verify/`, `*.xcodeproj/`, `Local.xcconfig`, `DerivedData/`, `.DS_Store`.

## Out of scope
- Any code or script.
- Editing the content of HANDOFF, decisions, the design review or the plan.
- Copying `support.js`, the PWA manifest or the icons.

## Acceptance (done.sh does not exist yet; run these literally)
```
test -f docs/handoff/HANDOFF.md
test "$(ls docs/handoff/screens/*.png | wc -l)" -eq 28
test -f "docs/handoff/Copy audit.dc.html" && test -f docs/handoff/Daytrack.dc.html
test ! -e docs/plan/handoff
grep -q 'docs/plan/AGENT_BRIEF.md' AGENTS.md
test "$(cat CLAUDE.md)" = "Read AGENTS.md before any task."
git diff --name-only origin/main...HEAD | grep -vE '^(docs/handoff/|docs/plan/handoff/|AGENTS.md|CLAUDE.md|\.gitignore)' ; test $? -eq 1
```
Each command exits 0. The last line prints nothing.
