## Goal
`SliderRowView` is presentational. It takes a `RowState` and closures: `onPreview`, `onCommit`, `onOpenPad` and `onDraggingChanged`.
- The value is set on touch-down.
- While held, the handle scales to 1.18, with no animation between the press and the value.
- It shows yesterday's tick.
- `.sensoryFeedback(.selection)` fires once per stop crossed, driven by RowState.
- The row is plain content on the warm background, with no custom glass.
- The value box is a separate button that calls `onOpenPad`.
- For accessibility, the row is adjustable (`accessibilityAdjustableAction`), and `accessibilityValue` comes from RowState.

The DEBUG catalog shows one row of each type.

## Why it matters
This is the daily interaction. Owner decision Q4 changes what a tap on the value does.
