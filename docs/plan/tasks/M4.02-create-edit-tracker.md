## Goal
**Create a custom tracker.** Show a type picker (numeric, ordinal, binary) with default labels, plus "Start from a common one" (the catalog). The type is never offered again once the tracker exists.

**Edit a tracker.**
- Name and SF Symbol change freely.
- Labels and anchors go through `TrackerManager.editWording`. Before the first closed value, the edit is free. After that, the screen shows "These words can change freely until the first day closes; after that, a change starts new wording from today." and the edit creates a revision.
- A fixed-type note explains that the type and the number of stops never change.

## Why it matters
Rules 6 and 7. The UI must be able to create revisions before the read side can show them.
